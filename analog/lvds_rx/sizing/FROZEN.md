**Rules from here on**

- A change to any file above re-opens the pre-layout regression for the affected benches and needs a new entry in
  `spec/decisions.yaml` and a new freeze note. Run `tools/audit_hashes.py` before trusting a gate table.
- Layout leaves built before the freeze must be regenerated from the frozen device table. Known to be out of date: the
  load-resistor (RL) and comparator-resistor (Rs) leaves, built at 19.664 um and 9.315 um; frozen values are 18.395 um
  and 8.862 um.
- Conditions attached to the freeze (from the audit, decision D-012): after extraction, re-check operating point, gain,
  delay and one eye run at ff/125C/3.6 V with the input common mode at 0.05 V; if gain there falls below 4 or a timing
  check fails, the constant-gm bias (ladder R6) is taken and the sizing is re-opened.
